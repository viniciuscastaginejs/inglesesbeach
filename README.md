# Pousada Ingleses Beach

Site estático em HTML, CSS e JavaScript, compatível com GitHub Pages e o domínio já configurado em CNAME.

## Páginas
- index.html — início e consulta de disponibilidade pelo WhatsApp.
- quartos.html — cartões com filtro por tipo de acomodação.
- quartos/joaquina.html
- quartos/canasvieiras.html
- quartos/jurere.html
- quartos/lagoa.html
- quartos/jacuzzi.html
- eventos.html — espaço para eventos.

## Idiomas
Português brasileiro, espanhol e inglês. A primeira visita segue a preferência suportada do navegador. O parâmetro ?lang=pt-BR, ?lang=es ou ?lang=en tem prioridade. A escolha manual fica salva neste navegador. Não há geolocalização por IP.

## Fotos
43 fotos de acomodações enviadas pelo proprietário, separadas por quarto. As duas fotos de áreas externas enviadas junto à suíte Jacuzzi são tratadas como áreas comuns. Imagens em WebP. Fotos específicas de eventos e imagens da praia foram preservadas da versão anterior.

## Publicação
Copiar todo o conteúdo deste pacote para a raiz do repositório, mantendo os diretórios assets/ e quartos/. Preservar CNAME. A hospedagem existente é responsável por publicar a branch configurada.

## Validação
Verificados os caminhos locais das oito páginas, arquivos de imagem, sintaxe JavaScript e correspondência dos grupos de fotos. A inspeção visual e os testes interativos em navegador continuam pendentes, porque a prévia local não ficou acessível no navegador de teste.
